# Muse — сучасний шаблон лендингу для AI-генератора контенту

Преміальний односторінковий сайт, готовий до продажу як шаблон або як основа для сайту клієнта.
Працює без збірки, фреймворків і залежностей: відкрийте `index.html`, і він працює.

## Що всередині

- Hero-блок з анімованою «AI-студією»: промпт друкується сам, з'являється завантаження, потім нові «згенеровані» зображення
- Інтерактивне демо «Try it»: 3 вкладки (реклама, опис товару, email), відповідь AI «друкується» як у ChatGPT
- Галерея «Made with Muse»: AI-арт намальований чистим CSS, тож жодних картинок не треба ліцензувати
- Стрічка логотипів клієнтів (marquee)
- Сітка можливостей (bento grid) зі світінням за курсором
- Блок «як це працює» з анімованими метриками
- Тарифи з кредитами та перемикачем «місяць / рік»
- Відгуки, FAQ-акордеон, CTA-форма з валідацією
- Темна тема за замовчуванням + перемикач на світлу (вибір запам'ятовується)
- Повністю адаптивний: телефон, планшет, ПК
- Доступність: skip-link, ARIA, клавіатурна навігація, `prefers-reduced-motion`
- SEO: meta description, Open Graph, семантична розмітка
- Контент видно навіть з вимкненим JavaScript

## Структура

```
index.html        — уся розмітка
css/style.css     — стилі (кольори змінюються в :root на початку файлу)
js/main.js        — інтерактивність (~150 рядків, без бібліотек)
assets/favicon.svg
```

## Як змінити під себе

1. **Бренд-кольори**: змініть `--accent` і `--accent-2` на початку `css/style.css`, і весь сайт перефарбується.
2. **Назва і тексти**: замініть «Muse» та тексти в `index.html`.
3. **Демо-відповіді**: тексти для вкладок «Try it» лежать в об'єкті `demos` у `js/main.js`.
4. **Галерея**: класи `art--1` … `art--6` можна замінити на справжні зображення (`<img>`) з вашого генератора.
5. **Форма**: у `js/main.js` (блок `CTA form`) підключіть Formspree, Mailchimp, ConvertKit тощо.
6. **Логотип**: замініть `assets/favicon.svg`.

## Як опублікувати безкоштовно

- **GitHub Pages**: Settings → Pages → Branch → `/ (root)`.
- **Netlify / Vercel**: перетягніть папку або підключіть репозиторій.

## Як заробити на цьому тисячі доларів

Чесно: сам по собі шаблон рідко продається за тисячі доларів одним платежем. Реальні шляхи:

| Модель | Де | Реалістична ціна |
|---|---|---|
| Продаж шаблону (багато разів) | ThemeForest, Gumroad, Lemon Squeezy, Creative Market | $19–79 за копію |
| Сайт під ключ для клієнта | Upwork, Fiverr, LinkedIn, місцевий бізнес | $500–3 000+ за проєкт |
| Продаж готового бізнесу | Flippa, Acquire.com | ціна залежить від трафіку й доходу, а не від дизайну |

**Найшвидший шлях до $1 000+:** AI-стартапів зараз запускається дуже багато, і всім потрібен лендинг.
Шукайте клієнтів на Product Hunt, у X/Twitter (#buildinpublic), Indie Hackers і в AI-спільнотах Discord.
Пропонуйте «лендинг під ключ за 3 дні» з вашими кольорами, текстами, доменом і формою заявок.
Один шаблон дає 5–10 клієнтів, бо змінюються лише кольори й тексти.

**Щоб шаблон продавався дорожче:** підключіть справжній AI (наприклад, Claude API) до блоку «Try it».
Живе демо, а не заготовлені тексти, — сильний аргумент для покупця.

**Щоб продати сайт як бізнес на Flippa дорожче:** потрібні трафік, email-підписники або дохід.
Покупці платять за цифри, а не за код.
