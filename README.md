# Muse — сучасний сайт для AI-генератора контенту

Преміальний багатосторінковий сайт для AI-стартапу з **живим AI-демо на базі Claude**.
Готовий до продажу як шаблон або як основа сайту для клієнта.

## Що всередині

**8 сторінок:**

| Сторінка | Що на ній |
|---|---|
| `index.html` | Головна: AI-студія в hero, можливості, живе демо, галерея, тарифи, відгуки, FAQ |
| `about.html` | Про компанію: історія, цінності, команда, вакансії |
| `blog.html` | Блог: головна стаття, 6 карток, підписка на розсилку |
| `blog-post.html` | Шаблон статті з типографікою (заголовки, цитати, списки) |
| `login.html` | Вхід і реєстрація з перемикачем, кнопкою Google і перевіркою полів |
| `privacy.html`, `terms.html` | Шаблони політики конфіденційності та умов використання |
| `404.html` | Сторінка «не знайдено» |

**Функції:**
- **Живе AI-демо**: вкладка «✦ Your prompt», відвідувач пише запит, а Claude відповідає потоком
- Три готові приклади, які працюють навіть без сервера
- Анімована «AI-студія»: промпт друкується сам, потім з'являються нові «згенеровані» зображення
- AI-арт намальований чистим CSS, тож не треба ліцензувати картинки
- Темна тема за замовчуванням + перемикач на світлу (вибір запам'ятовується)
- Адаптивність: телефон, планшет, ПК
- SEO: meta-теги, Open Graph-картинка для соцмереж, `sitemap.xml`, `robots.txt`, маніфест
- Доступність: ARIA, клавіатура, `prefers-reduced-motion`; контент видно і без JavaScript

## Структура

```
*.html                  — сторінки
css/style.css           — усі стилі (кольори в :root на початку файлу)
js/main.js              — інтерактивність, без бібліотек
api/generate.js         — серверна функція для живого AI-демо (Vercel)
assets/                 — логотип і картинка для соцмереж (og-image.png)
.github/workflows/      — автопублікація на GitHub Pages
```

## Публікація

### Варіант 1: Vercel (рекомендовано, працює живий AI)

1. Зареєструйтесь на [vercel.com](https://vercel.com) через GitHub.
2. **Add New → Project** → оберіть цей репозиторій → **Deploy**.
3. Отримайте ключ API на [console.anthropic.com](https://console.anthropic.com).
4. У Vercel: **Settings → Environment Variables** → додайте `ANTHROPIC_API_KEY` зі своїм ключем.
5. **Deployments → Redeploy**. Готово: вкладка «✦ Your prompt» відповідає справжнім AI.

### Варіант 2: GitHub Pages (безкоштовно, без живого AI)

1. У репозиторії: **Settings → Pages → Source: GitHub Actions**.
2. Зробіть будь-який push або запустіть workflow **Deploy to GitHub Pages** вручну (вкладка **Actions**).
3. Сайт з'явиться на `https://<ваш-логін>.github.io/<репозиторій>/`.

GitHub Pages віддає лише статичні файли, тож на ньому працюють три готові приклади,
а вкладка «Your prompt» показує повідомлення, що потрібен сервер.

## Живе AI-демо: як працює і скільки коштує

- Ключ API зберігається **тільки на сервері** (у змінній середовища), відвідувачі його не бачать.
- Модель: Claude Opus 5.5 (`claude-opus-5-5`), режим `effort: low` для швидких коротких відповідей.
- Увімкнено автоматичний резервний режим (`fallbacks: "default"`): якщо модель відхилить запит,
  API сам повторить його на іншій моделі.
- Захист: запит до 600 символів, відповідь до ~150 слів, до 8 запитів на годину з одного IP.
- Ціна: $4 за 1 млн вхідних і $20 за 1 млн вихідних токенів (разом із «роздумами» моделі). Одна відповідь демо коштує орієнтовно
  1–2 центи, тобто 1 000 генерацій ≈ $10–20. Поставте ліміт витрат у консолі Anthropic.
- Щоб зменшити витрати, у `api/generate.js` можна замінити модель на дешевшу (`claude-haiku-5-5`).

Ліміт запитів у функції «найкращий можливий»: він живе в пам'яті одного екземпляра сервера.
Для серйозного трафіку підключіть Vercel KV чи Upstash Redis.

## Як змінити під себе

1. **Кольори**: `--accent`, `--accent-2`, `--accent-3` на початку `css/style.css`.
2. **Назва і тексти**: замініть «Muse» в усіх `.html`-файлах (пошук і заміна по проєкту).
3. **Поведінка AI**: `SYSTEM_PROMPT` в `api/generate.js`.
4. **Готові приклади демо**: об'єкт `demos` у `js/main.js`.
5. **Форми підписки**: у `js/main.js` блок `Email sign-up forms` — підключіть Mailchimp, ConvertKit, Formspree.
6. **Вхід/реєстрація**: зараз це інтерфейс без бекенду. Підключіть Supabase Auth, Clerk або Firebase.
7. **Домен**: замініть `example.com` у `sitemap.xml` і `robots.txt`.
8. **Шапка й футер** однакові на всіх сторінках: змінюючи меню, оновіть кожен `.html`.
