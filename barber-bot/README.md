# Telegram-бот запису для салонів, барбершопів і студій

Клієнт сам обирає послугу, майстра, день і час. Власник і майстер одразу отримують сповіщення,
а клієнт — нагадування за 24 і за 2 години до візиту.

## Що вміє

**Для клієнтів**
- ✂️ Запис: послуга → майстер (або «будь-який вільний») → день → вільний час → телефон → підтвердження.
- Показує лише вільний час. Двох людей на один слот записати неможливо.
- 📋 «Мої записи»: перегляд і скасування.
- ⏰ Нагадування за 24 год і за 2 год з кнопкою «Не зможу прийти», щоб клієнти менше не приходили.
- 💈 Послуги й ціни, 📍 адреса, графік, Instagram.

**Для власника**
- Сповіщення про кожен новий запис і скасування з ім'ям та телефоном клієнта.
- Кнопка «Скасувати» під записом, клієнт отримає повідомлення.
- Команди: `/today`, `/tomorrow`, `/week`, `/stats` (скільки записів дав бот за 30 днів).
- Майстер отримує сповіщення про свої записи, якщо вказати його `tg_id` у `config.py`.

## Запуск за 10 хвилин

### 1. Створіть бота в Telegram
1. Відкрийте [@BotFather](https://t.me/BotFather) → `/newbot`.
2. Назва: назва бізнесу клієнта. Юзернейм: наприклад `studio_booking_bot` (має закінчуватися на `bot`).
3. Скопіюйте токен вигляду `123456789:AAH...`. **Нікому його не показуйте.**
4. Необов'язково: `/setuserpic` (логотип), `/setdescription` («Запис у салон за 30 секунд»).

### 2. Запустіть на комп'ютері (для демо)
Потрібен Python 3.10+ ([python.org](https://www.python.org/downloads/), на Windows поставте галочку «Add to PATH»).

```bash
cd barber-bot
pip install -r requirements.txt
cp .env.example .env        # на Windows: copy .env.example .env
```
Відкрийте `.env` блокнотом і вставте токен у `BOT_TOKEN=`. Потім:
```bash
python bot.py
```
Напишіть боту `/myid`, впишіть цей номер у `ADMIN_IDS=` у `.env` і перезапустіть.
Тепер вам приходитимуть сповіщення про записи.

Бот працює, поки відкрите вікно. Для справжнього клієнта потрібен сервер (крок 4).

### 3. Налаштуйте під барбершоп
Усе змінюється у файлі `config.py`: назва, адреса, телефон, Instagram, послуги з цінами й тривалістю,
майстри та графік роботи. Після змін перезапустіть бота.

### 4. Сервер, щоб бот працював 24/7
Найпростіше орендувати VPS за ~$4–5 на місяць ([Hetzner](https://www.hetzner.com/cloud),
[DigitalOcean](https://www.digitalocean.com)), Ubuntu. Включіть цю суму в щомісячну плату клієнта.

```bash
sudo apt update && sudo apt install -y python3-pip git
git clone https://github.com/hozvoc-svg/-.git bots && cd bots/barber-bot
pip3 install -r requirements.txt
nano .env   # вставити BOT_TOKEN і ADMIN_IDS
```
Автозапуск (бот підніметься сам після перезавантаження сервера):
```bash
sudo tee /etc/systemd/system/aztec-bot.service > /dev/null <<UNIT
[Unit]
Description=Booking bot
After=network-online.target

[Service]
WorkingDirectory=$PWD
ExecStart=/usr/bin/python3 bot.py
Restart=always

[Install]
WantedBy=multi-user.target
UNIT
sudo systemctl enable --now aztec-bot
```
Логи: `journalctl -u aztec-bot -f`. На одному сервері можна тримати ботів для багатьох клієнтів
(окрема папка, `.env` і сервіс на кожного).

## Новий клієнт = копія папки
Скопіюйте `barber-bot` → `salon-bot`, змініть `config.py` (послуги, майстри, графік, тексти)
і створіть нового бота в @BotFather. Код підходить для будь-якого бізнесу із записом за часом:
манікюр, масаж, СТО, репетитори, стоматологія.

## Тести
```bash
python -m unittest -v test_bot
```
Тести імітують Telegram і перевіряють увесь сценарій запису, захист від подвійного запису,
скасування та нагадування.

## Як продати бота

**Ціна:** 3 000–5 000 грн за налаштування + 300–500 грн на місяць (сервер, підтримка, зміни цін і графіка).

**Що сказати власнику:**
> Клієнти записуються самі 24/7, навіть уночі, коли ви не берете трубку.
> Бот сам нагадує про візит, тому менше людей не приходить.
> Вам і майстрам приходить сповіщення з ім'ям і телефоном.
> Тиждень безкоштовно. Якщо не сподобається, просто вимкнемо.

**Як запустити в барбершопі:** QR-код на бота біля каси й на дзеркалах, посилання в шапці Instagram,
у Google Maps (поле «Запис») і в автовідповіді Viber.

Через 2–3 тижні покажіть власнику `/stats`: «бот дав вам 40 записів». Це найкращий аргумент
для щомісячної оплати й для рекомендацій іншим бізнесам.
